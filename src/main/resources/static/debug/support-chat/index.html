Tixy 지원 채팅 디버그 콘솔

브라우저 한 화면에서 지원 채팅 REST, STOMP, 읽음 처리, AI 선응답, 운영 제어 흐름을 순서대로 검증하는 개발 전용 콘솔입니다. 역할 모드를 바꾸면 현재 테스트해야 할 순서와 허용된 버튼이 함께 바뀝니다.

개발 전용 페이지 운영 환경에는 노출하지 않고 로컬 또는 내부 개발 환경에서만 사용하세요.
WebSocket Endpoint /ws/support
Publish Prefix /pub/support/v1
Subscribe Prefix /sub/support/v1
User Queue Prefix /user/queue/support/v1
콘솔 모드 USER는 고객 흐름, ADMIN은 실제 상담원 흐름, SUPER_ADMIN은 운영 전용 관리자 흐름을 검증합니다.
CUSTOMER FLOW

고객 모드

문의방 생성부터 메시지 전송, 읽음 처리, AI 선응답 확인까지 고객 입장에서 순서대로 검증합니다.

STEP 1 JWT 입력 후 연결

토큰을 입력하고 STOMP 연결이 정상적으로 완료되는지 확인합니다.

STEP 2 방 선택과 구독

roomId를 잡고 실시간 메시지/읽음 이벤트 구독을 준비합니다.

STEP 3 핵심 액션 실행

현재 역할에서 허용된 버튼만 눌러 응답과 상태 변화를 확인합니다.

TEST GUIDE

이번 모드 체크포인트

USER

현재 모드에서 먼저 확인할 API와 STOMP 흐름을 순서대로 안내합니다.

STEP 1

연결

연결 안 됨

JWT를 넣고 Connect를 누르면 STOMP 연결을 시작합니다.

STEP 2

방 구독

구독 없음

roomId를 넣고 Subscribe를 누르면 메시지와 읽음 이벤트를 같은 화면에서 받습니다.

메시지 구독 경로 /sub/support/v1/rooms/{roomId}
읽음 구독 경로 /sub/support/v1/rooms/{roomId}/read
개인 unread 경로 /user/queue/support/v1/read

현재 방 상태

상태 미확인

방 생성, 내 문의방 목록 조회, 문의방 종료, 큐 이벤트 수신 뒤에 현재 roomId의 OPEN/CLOSED 상태를 바로 확인합니다.

STEP 3A

운영 전용 제어

큐 미구독

운영자 모드에서는 대기열 조회와 방 배정, 재배정, 종료 흐름을 검증합니다.

큐 구독 경로 /sub/support/v1/queue

STEP 3B

메시지 전송

현재 roomId 기준으로 텍스트 메시지를 전송합니다. CLOSED 방이면 서버 차단 여부까지 함께 확인합니다.

현재 역할에서 허용된 경우에만 메시지 전송을 테스트할 수 있습니다.

/pub/support/v1/rooms/{roomId}/messages

STEP 3C

AI 선응답

현재 방의 최근 고객 메시지를 바탕으로 간단한 AI 선응답을 생성합니다. 생성된 응답은 일반 메시지처럼 senderType=AI로 저장되고 브로드캐스트됩니다.

SUPER_ADMIN 모드에서는 운영 전용 정책 때문에 AI 초안 생성이 비활성화됩니다.

AI Provider 상태 미확인

현재 AI mode / provider / 모델 정보를 아직 조회하지 않았습니다.

RAG 상태 미확인

RAG를 아직 조회하지 않았습니다.

문서 개수 -
topK -
유사도 기준 -
GET /api/support/v1/ai/config
상담원 연결 상태 미확인

문의방 상세 조회 후 상담원 연결 요청 가능 여부를 확인할 수 있습니다.

POST /api/support/v1/rooms/{roomId}/ai-replies POST /api/support/v1/rooms/{roomId}/counselor-request

STEP 3D

읽음 처리

마지막으로 읽은 메시지 ID를 보내고 읽음 이벤트와 unread sync가 어떻게 반영되는지 확인합니다.

실제 참여자 역할일 때만 읽음 처리를 테스트할 수 있습니다.

/pub/support/v1/rooms/{roomId}/read

STEP 3E

REST 테스트

방 생성, 방 목록, 방 상세, 메시지 이력을 같은 화면에서 확인합니다.

로그 정리

이벤트, 에러, RAW, REST 영역을 각각 비울 수 있습니다.
