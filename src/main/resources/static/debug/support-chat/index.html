Tixy 지원 채팅 디버그 콘솔

별도 프론트 없이 브라우저에서 바로 지원 채팅 REST와 STOMP 계약을 검증하는 개발 전용 콘솔입니다. room 상태, 메시지, 읽음, AI 응답과 운영 제어 흐름까지 한 화면에서 확인할 수 있습니다.

개발 전용 페이지 운영 환경에서는 이 경로를 외부에 노출하지 않는 편이 안전합니다.
WebSocket Endpoint /ws/support
Publish Prefix /pub/support/v1
Subscribe Prefix /sub/support/v1
User Queue Prefix /user/queue/support/v1
콘솔 모드 USER는 고객 흐름, ADMIN은 대기열 조회와 방 배정, 종료 같은 운영 흐름을 테스트할 때 사용합니다.

연결

연결 안 됨

JWT를 넣고 Connect를 누르면 STOMP 연결을 시작합니다.

방 구독

구독 없음

roomId를 넣고 Subscribe를 누르면 메시지와 읽음 이벤트를 같은 화면에서 받습니다.

메시지 구독 경로 /sub/support/v1/rooms/{roomId}
읽음 구독 경로 /sub/support/v1/rooms/{roomId}/read
개인 unread 경로 /user/queue/support/v1/read

현재 방 상태

상태 미확인

방 생성, 내 문의방 목록 조회, 문의방 종료, 큐 이벤트 수신 뒤에 현재 roomId의 OPEN/CLOSED 상태를 바로 확인합니다.

관리자 도구

큐 미구독

ADMIN 토큰으로 대기열 조회, 방 배정, 배정 해제, 재배정, 종료 흐름을 검증합니다.

큐 구독 경로 /sub/support/v1/queue

메시지 전송

현재 roomId 기준으로 텍스트 메시지를 전송합니다. CLOSED 방이면 서버 차단 여부도 함께 확인합니다.

/pub/support/v1/rooms/{roomId}/messages

AI 선응답

현재 방의 최근 고객 메시지를 바탕으로 간단한 AI 선응답을 생성합니다. 생성된 응답은 일반 메시지처럼 senderType=AI로 저장되고 브로드캐스트됩니다.

POST /api/support/v1/rooms/{roomId}/ai-replies

읽음 처리

마지막으로 읽은 메시지 ID를 보내고 읽음 이벤트와 unread sync가 어떻게 반영되는지 확인합니다.

/pub/support/v1/rooms/{roomId}/read

REST 테스트

방 생성, 방 목록, 방 상세, 메시지 이력 조회를 같은 화면에서 확인합니다.

로그 정리

이벤트, 에러, RAW, REST 영역을 각각 비울 수 있습니다.

메시지 타임라인

0건

수신한 USER, COUNSELOR, AI 메시지가 시간 역순으로 쌓입니다.

읽음 / 시스템 이벤트

방 읽음 이벤트, 개인 unread sync, 대기열 이벤트를 확인합니다.
