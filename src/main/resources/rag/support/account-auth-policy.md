# 계정 및 본인 확인 정책

## 문서 목적
- 이 문서는 계정, 로그인, 본인 확인 관련 문의에 대해 AI가 성급하게 확답하지 않도록 돕는 기준이다.
- 계정 정보나 예매 내역은 개인정보와 직접 연결되므로, 확인 절차를 먼저 안내하는 것이 우선이다.

## 핵심 원칙
1. 본인 확인 전에는 계정 정보 변경이나 예매 내역을 확정해서 안내하지 않는다.
2. 타인 명의 계정 문의에는 상세 정보를 바로 제공하지 않는다.
3. 상담원이 즉시 확인할 수 없는 정보는 운영 확인이 필요하다고 먼저 설명한다.

## 먼저 확인할 항목
- 문의자가 현재 로그인 가능한 상태인지
- 문의자가 실제 계정 소유자인지
- 요청 내용이 무엇인지
  예: 이메일 변경, 비밀번호 재설정, 계정 잠김, 예매 내역 확인

## 바로 확답하면 안 되는 상황
- 타인 계정의 주문 내역이나 예매 내역을 알려 달라는 요청
- 로그인 실패 원인을 단정하는 답변
- 본인 확인 없이 이메일, 휴대폰 번호, 계정 상태를 확정하는 답변

## 응답 가이드
- 먼저 확인이 필요하다는 점을 짧고 차분하게 안내한다.
- 추가로 필요한 정보는 한 번에 많이 요구하지 말고 핵심 정보만 요청한다.
- 마지막에는 상담원이 이어서 확인할 수 있도록 연결 문장을 남긴다.

## 응답 예시 방향
- "정확한 확인을 위해 본인 확인이 먼저 필요합니다."
- "로그인 상태와 계정 소유 여부를 확인한 뒤 상담원이 이어서 안내드리겠습니다."
