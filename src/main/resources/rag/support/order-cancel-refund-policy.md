# 예매 취소, 환불, 주문 만료 정책

## 문서 목적
- 이 문서는 TIXY 본 서비스의 실제 주문/결제 흐름을 기준으로 예매 취소, 환불, 결제 만료 문의에 답변하기 위한 정책이다.
- 현재 TIXY에는 고객이 화면에서 즉시 직접 취소/환불을 완료하는 기능이 확인되지 않는다.
- 따라서 AI는 취소 완료, 환불 승인, 환불 예정일을 단정하지 말고 주문/결제/좌석 상태 확인이 필요하다고 안내해야 한다.
- 고객에게 답변할 때는 내부 결제 처리 방식, 개발자용 상태명, 시스템 기능명, 데이터 처리 용어를 그대로 쓰지 않는다.
- 쉬운 표현으로 바꿔 말한다: "입금 확인", "입금 내역 확인", "결제 대기 상태", "예매 완료 상태", "결제 가능 시간이 지난 상태".

## TIXY 주문/결제 흐름 요약
1. 고객이 좌석을 선택하면 좌석이 잠시 임시 확보된다.
2. 좌석 홀드 유효 시간은 5분이다.
3. 주문 생성 시 결제 대기 상태가 된다.
4. 주문 생성 응답에는 총 결제 금액, USDT 환산 금액, 입금 주소, 티켓 수량이 포함된다.
5. 입금 내역이 정상 확인되면 주문은 예매 완료 상태가 된다.
6. 결제 성공 시 좌석이 예약 처리되고 티켓 정보가 생성된다.
7. 좌석 홀드 시간이 지난 뒤 결제가 들어오면 결제 가능 시간이 지난 건으로 처리되고 입금 금액은 고객 포인트로 보상될 수 있다.

## 상태별 응대 기준

### 좌석 홀드 상태
- 고객이 좌석을 잡았지만 아직 주문/결제가 확정되지 않은 상태이다.
- 5분 내 주문과 결제가 진행되어야 한다.
- 홀드 만료 후에는 같은 좌석을 보장할 수 없다.
- 안내 문구: "좌석은 선택 후 5분 동안만 임시 확보됩니다. 시간이 지나면 좌석이 다시 풀릴 수 있어요."

### 주문 대기 상태
- 주문은 생성되었지만 입금이 아직 확인되지 않은 상태이다.
- 고객에게 입금 주소와 결제 금액을 다시 확인하도록 안내한다.
- 이미 입금했다고 하면 주문번호, 입금 시각, 입금에 사용한 주소 일부, 입금 완료 화면 확인이 필요하다.
- 안내 문구: "주문은 생성되어 있지만 아직 입금 확인 전 상태로 보여요. 이미 입금하셨다면 주문번호와 입금 시각을 알려 주세요."

### 결제 완료 상태
- 주문 결제가 확인되어 좌석이 예약 처리된 상태이다.
- 취소/환불 요청은 자동 확정하지 않는다.
- 상담원이 공연 시작 시간, 예매 상태, 결제 내역을 확인해야 한다.
- 안내 문구: "결제가 완료된 예매는 공연 상태와 요청 시점 확인 후 취소 가능 여부를 안내드릴 수 있습니다."

### 결제 가능 시간 만료
- 좌석 홀드 5분이 지난 뒤 결제가 들어오면 결제 가능 시간이 만료된 것으로 처리될 수 있다.
- 이 경우 좌석은 다시 선택 가능한 상태로 풀리고 주문은 결제 가능 시간이 지난 상태가 된다.
- 결제 금액은 포인트로 보상될 수 있다.
- 안내 문구: "결제 가능 시간이 지난 뒤 입금된 건은 좌석 확정이 어려울 수 있고, 확인 후 포인트 보상으로 처리될 수 있습니다."

### 입금 내역 연결 확인 필요
- 입금 지갑 주소로 대기 중인 주문을 찾지 못하면 포인트 보상 또는 환불 예정 처리가 필요하다.
- TIXY 회원 지갑 주소와 연결되면 포인트 보상 상태가 될 수 있다.
- 지갑 주소 소유 고객도 찾지 못하면 환불 예정 상태로 저장되고 운영 확인이 필요하다.
- 안내 문구: "입금 내역과 예매 정보를 바로 연결하지 못한 경우가 있어요. 주문번호, 입금 시각, 입금에 사용한 주소 일부를 알려 주시면 확인해 드릴게요."

## 먼저 확인할 항목
- 주문번호 또는 예매번호가 있는지
- 공연명과 회차 일시
- 선택 좌석 또는 구역
- 결제 여부와 결제 시각
- 송금 지갑 주소
- 입금 완료 화면 또는 송금 확인 번호가 있다면 해당 정보
- 고객이 원하는 처리가 취소, 환불, 포인트 보상 확인, 재예매 중 무엇인지

## 바로 확답하면 안 되는 상황
- "취소 완료되었습니다"라고 말하는 것
- "환불은 언제까지 됩니다"라고 날짜를 보장하는 것
- 공연 시작 후 환불 가능 여부를 단정하는 것
- 만료 입금 건을 원 결제 수단으로 즉시 환불한다고 확정하는 것
- 포인트 보상과 환불 예정 중 어느 쪽인지 확인 없이 단정하는 것
- 좌석 변경이나 부분 환불이 가능하다고 먼저 약속하는 것

## 답변 가이드
- 고객 불안을 줄이되, 확정 처리는 상담원이 확인한다고 안내한다.
- 필요한 정보는 한 번에 너무 많이 요구하지 말고 핵심 2~3개부터 요청한다.
- 주문/결제 확인이 필요한 경우에는 주문번호 또는 예매번호를 우선 요청한다.
- 만료 입금이나 입금 내역 확인이 필요한 경우에는 "포인트 보상 또는 운영 확인" 가능성을 안내한다.

## 응답 예시
- "취소 가능 여부는 공연 시작 시점과 현재 예매 상태를 확인한 뒤 안내드릴 수 있습니다. 주문번호나 예매번호를 알려 주시면 상담원이 이어서 확인해 드릴게요."
- "이미 입금하셨다면 주문번호, 입금 시각, 입금에 사용한 주소 일부를 알려 주세요. 입금 내역과 예매 상태를 확인한 뒤 안내드리겠습니다."
- "좌석 홀드 시간이 지난 뒤 입금된 경우에는 좌석 확정이 어려울 수 있습니다. 이 경우 포인트 보상 또는 운영 확인이 필요할 수 있어요."
