# 고객센터 예시 질문 및 답변 방향

## 문서 목적
- 이 문서는 고객 채팅 화면의 추천 질문과 AI 선응답 방향을 TIXY 실제 예매/결제 흐름에 맞추기 위한 예시 모음이다.
- 질문 버튼으로 들어온 문장도 일반 고객 메시지와 동일하게 처리한다.
- 답변은 2~4문장 안에서 짧게 하고, 확정 처리가 필요한 내용은 상담원 확인으로 연결한다.

## 예시 질문과 답변 방향

### 1. 예매 취소/환불
- 예시 질문: 예매 취소하면 환불은 언제 되나요?
- 실제 기준: 현재 고객 직접 취소/환불 완료 API는 확인되지 않는다. 주문 상태, 공연 시작 시점, 결제 처리 상태 확인이 필요하다.
- 답변 방향: 취소 가능 여부와 환불 반영 시점은 확인 후 안내 가능하다고 말한다. 주문번호 또는 예매번호를 요청한다.
- 예시 답변: "취소 가능 여부는 공연 시작 시점과 현재 예매 상태를 확인한 뒤 안내드릴 수 있어요. 주문번호나 예매번호를 알려 주시면 상담원이 이어서 확인해 드릴게요."

### 2. 좌석 변경
- 예시 질문: 좌석 변경이 가능한가요?
- 실제 기준: 좌석은 `AVAILABLE`, `HELD`, `RESERVED` 상태를 가진다. 결제 확정 후 좌석은 `RESERVED`가 되며, 자동 좌석 변경 API는 확인되지 않는다.
- 답변 방향: 같은 회차 내 변경 가능 여부는 현재 예매 상태와 잔여 좌석 확인이 필요하다고 안내한다.
- 예시 답변: "좌석 변경은 현재 예매 상태와 잔여 좌석 확인이 필요합니다. 공연명, 회차, 현재 좌석 정보를 알려 주시면 상담원이 가능한 범위를 확인해 드릴게요."

### 3. 배송 주소 변경
- 예시 질문: 티켓 배송 주소를 변경하고 싶어요.
- 실제 기준: 현재 TIXY 백엔드에는 배송 상태나 운송장 API가 확인되지 않는다. 모바일 티켓/실물 배송 여부 확인이 먼저 필요하다.
- 답변 방향: 배송 대상 예매인지 먼저 확인하고, 배송 시작 여부에 따라 변경 가능성이 달라질 수 있다고 안내한다.
- 예시 답변: "먼저 해당 예매가 모바일 티켓인지 배송 티켓인지 확인이 필요합니다. 배송 대상 예매라면 배송 시작 여부에 따라 주소 변경 가능성이 달라질 수 있어 상담원이 확인해 드릴게요."

### 4. 모바일 티켓 미노출
- 예시 질문: 모바일 티켓이 안 보여요.
- 실제 기준: 입금 웹훅이 정상 처리되어 주문이 `CONFIRMED`되고 좌석이 `RESERVED`된 뒤 티켓 레코드가 생성된다. 입금 직후에는 반영 지연이 있을 수 있다.
- 답변 방향: 로그인 계정, 예매 내역 표시 여부, 주문/트랜잭션 정보를 확인한다.
- 예시 답변: "모바일 티켓은 결제 확인 후 예매 내역에 반영됩니다. 입금 직후라면 조금 지연될 수 있고, 계속 보이지 않으면 주문번호나 트랜잭션 ID를 알려 주세요."

### 5. 결제 수단 변경/영수증
- 예시 질문: 결제 수단 변경이나 영수증 발급이 가능한가요?
- 실제 기준: 주문 생성 후 입금 주소로 결제하는 구조이며, 결제 확정은 웹훅으로 처리된다. 결제 수단 변경 API나 영수증 발급 API는 확인되지 않는다.
- 답변 방향: 주문 상태 확인이 필요하고, 영수증/결제 증빙은 결제 완료 내역 기준으로 상담원이 확인한다고 안내한다.
- 예시 답변: "결제 수단 변경은 현재 주문 상태 확인이 필요합니다. 영수증이나 결제 증빙도 결제 완료 내역 기준으로 확인해야 해서 주문번호를 알려 주세요."

### 6. 예매 내역 확인
- 예시 질문: 예매 내역을 확인하고 싶어요.
- 실제 기준: 예매 내역은 계정 및 결제 정보와 연결되므로 본인 확인 전 상세 정보를 제공하면 안 된다.
- 답변 방향: 로그인 계정 확인과 주문번호/공연명/회차 정보를 요청한다.
- 예시 답변: "예매 내역은 개인정보와 연결되어 있어 본인 확인이 먼저 필요합니다. 로그인 계정과 공연명 또는 주문번호를 알려 주시면 상담원이 확인해 드릴게요."

### 7. 입금했는데 예매가 안 보여요
- 예시 질문: 입금했는데 예매가 안 보여요.
- 실제 기준: 송금 지갑 주소로 `PENDING` 주문을 매칭한다. 주문이 없으면 포인트 보상 또는 환불 예정 확인이 필요할 수 있다.
- 답변 방향: 송금 지갑 주소 일부, 트랜잭션 ID, 입금 시각을 요청한다.
- 예시 답변: "입금 후 예매가 보이지 않는 경우 주문 매칭 상태 확인이 필요합니다. 송금 지갑 주소 일부와 트랜잭션 ID를 알려 주시면 상담원이 확인해 드릴게요."

### 8. 결제 시간이 지났어요
- 예시 질문: 좌석 선택 후 결제 시간이 지났는데 어떻게 되나요?
- 실제 기준: 좌석 홀드는 5분이며, 만료 후 결제가 들어오면 주문이 `EXPIRED` 처리되고 포인트 보상될 수 있다.
- 답변 방향: 같은 좌석 보장을 약속하지 않고, 주문/입금 상태 확인으로 연결한다.
- 예시 답변: "좌석은 선택 후 5분 동안만 임시 확보됩니다. 시간이 지난 뒤 입금된 경우 좌석 확정이 어려울 수 있어 주문번호나 트랜잭션 ID로 상태를 확인해 드릴게요."
