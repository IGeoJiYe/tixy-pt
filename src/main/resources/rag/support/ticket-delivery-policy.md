# 티켓 수령 및 배송 정책

## 문서 목적
- 이 문서는 모바일 티켓, 현장 수령, 배송 티켓 관련 문의에 대해 AI가 기본 흐름을 안정적으로 안내하도록 돕는 기준이다.
- 티켓 수령 방식에 따라 고객이 확인해야 할 항목이 달라지므로, 문의 유형을 먼저 구분하는 것이 중요하다.

## 핵심 원칙
1. 티켓 수령 방식이 무엇인지 먼저 확인한다.
2. 배송 티켓은 배송 시작 전과 후의 안내가 달라질 수 있다.
3. 현장 수령과 모바일 티켓은 고객이 준비해야 할 확인 수단을 분명히 알려 준다.

## 수령 방식별 기본 확인 항목

### 모바일 티켓
- 고객이 로그인 상태인지
- 예매 내역에서 공연이 정상 표시되는지
- 공연 시작 시간이 임박한 상태인지

### 현장 수령
- 예매 내역과 본인 확인 수단을 준비했는지
- 수령 장소와 수령 가능 시간을 확인했는지

### 배송 티켓
- 배송이 아직 시작 전인지
- 주소 변경 가능 여부를 확인해야 하는 상황인지
- 배송 시작 후라면 추가 운영 확인이 필요한 상황인지

## 바로 확답하면 안 되는 상황
- 배송이 이미 시작된 뒤 주소 변경 가능 여부를 즉시 단정하는 답변
- 모바일 티켓 미노출 원인을 한 가지로 단정하는 답변
- 현장 수령 조건을 확인 없이 확정하는 답변

## 응답 가이드
- 먼저 어떤 방식으로 티켓을 받는지 확인한다.
- 그 방식에 맞는 다음 확인 단계만 짧게 안내한다.
- 예외 처리 가능 여부는 상담원이 이어서 확인한다고 연결한다.

## 응답 예시 방향
- "티켓 수령 방식에 따라 확인 항목이 달라 먼저 수령 방식을 확인해 주세요."
- "배송이 이미 시작된 경우에는 주소 변경 가능 여부를 상담원이 추가로 확인해 드려야 합니다."
