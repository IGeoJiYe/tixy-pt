# 티켓 발급, 모바일 티켓, 수령 안내 정책

## 문서 목적
- 이 문서는 TIXY의 실제 티켓 생성 흐름을 기준으로 모바일 티켓, 예매 내역, 배송/수령 문의에 답변하기 위한 정책이다.
- 현재 TIXY는 결제 성공 후 모바일 티켓 정보를 생성하지만, 별도의 실물 배송 추적 기능이나 배송 상태 조회 기능은 확인되지 않는다.
- 따라서 배송 완료, 운송장, 현장 수령 확정 등은 단정하지 않는다.
- 고객에게 답변할 때는 내부 결제 처리 방식, 개발자용 상태명, 시스템 기능명, 데이터 처리 용어를 그대로 쓰지 않는다.
- 쉬운 표현으로 바꿔 말한다: "입금 확인", "예매 내역 반영", "모바일 티켓 발급 준비", "예매 완료 상태", "좌석 임시 확보".

## TIXY 티켓 발급 흐름
1. 좌석이 임시 확보된 동안 주문이 생성된다.
2. 입금이 정상 확인되면 주문은 예매 완료 상태가 된다.
3. 해당 좌석은 예약된 좌석으로 처리된다.
4. 좌석별 티켓 정보가 생성되고 좌석 위치가 함께 표시된다.
5. 생성 직후 모바일 티켓은 발급 준비 상태일 수 있다.

## 티켓 관련 상태 이해
- 선택 가능한 좌석: 고객이 예매할 수 있는 좌석
- 임시 확보된 좌석: 고객이 선택했지만 결제 확인 전인 좌석, 5분 내 결제 필요
- 예약된 좌석: 결제가 확인되어 예매 완료된 좌석
- 모바일 티켓 발급 준비: 결제 확인 후 티켓 정보가 생성되는 초기 상태
- 이후 상태 후보: 사용 완료, 취소, 환불, 만료

## 모바일 티켓 문의
### 먼저 확인할 항목
- 고객이 로그인 상태인지
- 예매가 결제 완료 상태인지
- 입금 후 충분한 시간이 지났는지
- 예매 내역 또는 마이티켓 화면에 공연이 표시되는지
- 같은 계정으로 예매했는지

### 안내 기준
- 입금 직후라면 입금 확인과 예매 내역 반영에 시간이 조금 걸릴 수 있다고 안내한다.
- 결제 확인 전이면 모바일 티켓이 보이지 않을 수 있다.
- 좌석 임시 확보 시간이 만료되었거나 결제 가능 시간이 지난 주문이라면 티켓이 정상 발급되지 않을 수 있다.
- 상담원 확인 전에는 티켓이 정상 발급됐다고 단정하지 않는다.

### 응답 예시
- "모바일 티켓은 결제 확인 후 예매 내역에 반영됩니다. 입금하신 지 얼마 되지 않았다면 처리 시간이 조금 걸릴 수 있어요."
- "마이티켓에 보이지 않는 경우 로그인 계정, 주문번호, 입금 시각을 알려 주시면 상담원이 발급 상태를 확인해 드릴게요."

## 배송 티켓 문의
- 현재 확인된 TIXY 기능에는 배송 상태, 운송장, 배송지 변경 기능이 없다.
- 실물 배송 여부는 공연/운영 정책 확인이 필요하다고 안내한다.
- 배송 주소 변경 가능 여부는 배송 시작 전후와 운영 정책에 따라 달라질 수 있으므로 단정하지 않는다.

### 응답 예시
- "현재 예매 건이 모바일 티켓인지 실물 배송 대상인지 먼저 확인이 필요합니다."
- "배송지 변경 가능 여부는 배송 시작 여부에 따라 달라질 수 있어 상담원이 예매 정보를 확인한 뒤 안내드릴게요."

## 현장 수령 문의
- 현재 확인된 TIXY 기능에는 현장 수령을 즉시 확정하는 기능이 없다.
- 현장 수령 가능 여부는 공연장 운영 정책과 예매 상태 확인이 필요하다.
- 고객에게 예매 내역과 본인 확인 수단 준비를 안내할 수 있다.

## 바로 확답하면 안 되는 상황
- "배송이 시작되었습니다"라고 단정하는 것
- "운송장 번호는 이렇습니다"라고 임의로 말하는 것
- "모바일 티켓은 정상 발급됐습니다"라고 확인 없이 단정하는 것
- "현장 수령 가능합니다"라고 운영 확인 없이 말하는 것
- 모바일 티켓이 발급 준비 상태인데 최종 확정 티켓이라고 단정하는 것

## 답변 가이드
- 모바일 티켓은 결제 확인과 예매 내역 반영 여부를 중심으로 안내한다.
- 배송/현장 수령은 실제 운영 확인이 필요하다고 말한다.
- 고객에게 주문번호, 예매 계정, 공연명/회차, 입금 시각을 요청한다.
